
# PredicateRange

Keep rows whose column value falls in a numeric, time, or duration range. `start` and `end` are inclusive by default; either may be null for an open-ended range. 

## Properties

Name | Type
------------ | -------------
`start` | number
`end` | number
`startUnit` | string
`endUnit` | string
`startExclusive` | boolean
`endExclusive` | boolean
`invert` | boolean
`toColumnId` | string
