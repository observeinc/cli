
# PredicateFilterCondition

A raw OPAL boolean condition, for filters the other predicates cannot express. The condition is stored as an opaque string and is not parsed or validated here. Supply the boolean expression on its own, without a surrounding filter verb — the verb comes from the enclosing `FilterRule`. 

## Properties

Name | Type
------------ | -------------
`condition` | string
`disabledCondition` | string
