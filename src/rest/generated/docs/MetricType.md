
# MetricType

Metric semantic type.  * `CumulativeCounter`: A metric that represents a non-decreasing counter with possible resets. * `Delta`: A metric that represents a change in a value over time * `Gauge`: A metric that represents a value that can increase or decrease * `TDigest`: A metric that represents a t-digest of values * `Sample`: A metric that represents a sample of values * `Histogram`: A metric that represents an OpenTelemetry explicit bucket histogram * `ExponentialHistogram`: A metric that represents an OpenTelemetry exponential histogram
