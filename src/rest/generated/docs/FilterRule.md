
# FilterRule

One filter rule: apply `predicate` to `column`, quantified by `verb`. Set `enabled: false` to keep a rule in the document but leave it out of the query. 

## Properties

Name | Type
------------ | -------------
`column` | [ColumnRef](ColumnRef.md)
`verb` | [FilterVerb](FilterVerb.md)
`enabled` | boolean
`predicate` | [FilterPredicate](FilterPredicate.md)
