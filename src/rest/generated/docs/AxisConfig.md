
# AxisConfig

Configuration for a single axis: whether it is shown, its label, bounds, scale, and number formatting. On a value axis `valueFormat` uses all of `CellNumberFormat`; on category and time axes only its `options` apply. 

## Properties

Name | Type
------------ | -------------
`show` | boolean
`label` | string
`domain` | [AxisConfigDomain](AxisConfigDomain.md)
`scaleType` | [LogScale](LogScale.md)
`valueFormat` | [CellNumberFormat](CellNumberFormat.md)
`hideGridLines` | boolean
`orient` | [AxisConfigOrient](AxisConfigOrient.md)
