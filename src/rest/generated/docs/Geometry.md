
# Geometry

A card\'s placement within its section\'s grid, measured from the section\'s top-left corner. `x` and `w` are in grid columns (the grid is 12 columns wide); `y` and `h` are in grid rows. 

## Properties

Name | Type
------------ | -------------
`x` | number
`y` | number
`w` | number
`h` | number
